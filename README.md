# Social app deployment

The project has a Vite/React frontend in `Client` and an Express, MongoDB, and
Socket.IO backend in `Server`. The backend blueprint is in `render.yaml`; the
Vercel SPA rewrite is in `Client/vercel.json`.

## Deploy the API to Render

1. Push this project to a GitHub repository and create a Render Blueprint from
   that repository. Render will use `render.yaml` to create the web service.
2. Set the service's `MONGODB_URI` to the production MongoDB connection string.
   Configure the MongoDB network access rules to allow connections from Render.
3. Set `CLIENT_URL` temporarily to `http://localhost:5173`; replace it with the
   deployed Vercel site origin after Vercel assigns one.
4. Set the three `CLOUDINARY_*` values if the app should upload images. `JWT_SECRET`
   is generated by the blueprint; keep it secret and do not rotate it casually,
   as doing so invalidates existing sessions.
5. Wait for the service to become healthy and note its public URL.

## Deploy the frontend to Vercel

1. Import the same GitHub repository into Vercel and set the project root
   directory to `Client`.
2. Set `VITE_API_URL` to the Render service's public origin (for example,
   `https://social-app-api.onrender.com`, without a trailing slash).
3. Build with `npm run build` and serve the `dist` output. Vercel detects Vite
   automatically; `Client/vercel.json` keeps client-side routes working on refresh.
4. After the Vercel URL is assigned, update Render's `CLIENT_URL` to that exact
   origin and redeploy the API.

The production API uses credentialed CORS and secure cross-site cookies so
browser sessions work between the Vercel and Render origins. Keep secrets in
the hosting providers' environment-variable settings, not in frontend variables
or committed `.env` files. `VITE_API_URL` is public and is compiled into the
frontend bundle.

For local development, create `Server/.env` using `Server/.env.example`, run
`npm install` in both `Server` and `Client` if needed, start the server with
`npm start` from `Server`, then start Vite with `npm run dev` from `Client`.
